Pydantic AI Field Guide · Mental model · docs/agent.md

The Agent is a reusable, typed container. You create it once at module level. Agent[DepsT, OutputT] means type checkers catch mistakes such as the wrong RunContext type in a tool or the wrong output type. A run (run, run_sync, run_stream, run_stream_events or iter) is a loop over pydantic-graph nodes: UserPromptNode, then ModelRequestNode, then CallToolsNode, repeating until the model produces something that validates against output_type. RunContext, usually called ctx, is your handle into the run: it carries your typed deps plus usage, retry count, run step, messages and the deadline, and offers emit, enqueue and cancel. In version 2, most of the old Agent keyword arguments became capabilities: reusable bundles of tools, hooks, instructions and settings.
