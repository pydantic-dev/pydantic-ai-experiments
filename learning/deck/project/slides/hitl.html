Human-in-the-loop: pause the run, resume with answers

agent = Agent('anthropic:claude-sonnet-5-5',
    output_type=[str, DeferredToolRequests])

@agent.tool_plain(requires_approval=True)
def delete_file(path: str) -> str:
    return f'deleted {path}'

r = agent.run_sync('Delete tmp.txt')
req = r.output  # DeferredToolRequests
res = req.build_results(approvals={
    c.tool_call_id: ToolDenied('No deletes')
    for c in req.approvals})
r = agent.run_sync(message_history=r.all_messages(),
                   deferred_tool_results=res)

Three ways to defer

  • requires_approval=True: always ask.
  • raise ApprovalRequired: ask only sometimes.
  • raise CallDeferred: run it elsewhere, answer later.

Or resolve inline

HandleDeferredToolCalls(policy) approves in the same run, e.g. refunds ≤ $100.

Approval is UX, not authorization: check permissions inside the tool.

Pydantic AI Field Guide · Tools · docs/deferred-tools.md

Deferred tools end the run with a DeferredToolRequests output, which has approvals, calls, metadata and validated_args. Include DeferredToolRequests in output_type, and remember that a run-time output_type replaces the agent’s, so pass both. To resume, run again with the message history and DeferredToolResults: approvals map tool call IDs to True, False, ToolApproved(override_args=...) or ToolDenied(message); calls map IDs to a value, ToolReturn, ModelRetry or ToolFailed. To pause across processes, store result.conversation with ConversationTypeAdapter and resume later with conversation=. The HandleDeferredToolCalls capability resolves requests inside the same run, through a policy function or a resume token that an approver answers via resolve_external_event; on AWS Lambda durable functions that wait is itself durable. Show approvers validated_args so they see exactly what will run. Security: UI clients submit approvals themselves, so an approval is not proof of authorization. Use cases: destructive file or DB operations, payments, emails, long-running external jobs.
