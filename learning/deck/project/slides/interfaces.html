Pydantic AI Field Guide · Interfaces · docs/interfaces.md, docs/ui/*.md, docs/web.md, docs/cli.md

All surfaces reuse the same Agent object, so tools, deps, approvals and history behave the same everywhere. clai is a terminal chat (uvx clai), with /usage, /markdown and /multiline commands and an --mcp-config flag for Claude-Desktop-style MCP configs. agent.to_web(models={...}) returns a Starlette app served on 127.0.0.1:7932, with a model picker and approval buttons; it only answers localhost or IP Host headers unless you pass allowed_hosts. For production frontends, AGUIAdapter.dispatch_request(request, agent=...) and VercelAIAdapter.dispatch_request(request, agent=..., sdk_version=6) convert a frontend request into run_stream_events and stream protocol events back as server-sent events. Agent.to_ag_ui() was removed in version 2. Trust model: the client sends the whole history, so the endpoint is not an auth boundary. The adapters strip client system prompts, drop dangling tool calls and reject non-JSON; prefer manage_message_history='server' and save result.all_messages() in on_complete. For a stop button, use a CancellationToken on a separate endpoint, since a client disconnect is not first-party cancellation. A2A (fasta2a) exposes agents to other agents.
