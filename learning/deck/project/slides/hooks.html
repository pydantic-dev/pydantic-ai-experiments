03 · Tools & capabilities

Hooks and custom capabilities intercept every step

Quick: the Hooks capability

hooks = Hooks()
@hooks.on.before_model_request
async def log(ctx, request_context):
    print('step', ctx.run_step)
    return request_context

@hooks.on.before_tool_execute(
    tools=['send_email'], timeout=5)
async def audit(ctx, *, call, tool_def, args):
    print('audit:', call.tool_name, args)
    return args

Reusable: subclass a capability

@dataclass
class Audit(AbstractCapability[Any]):
    count: int = 0
    async def for_run(self, ctx):
        return Audit()  # per-run state

    async def wrap_tool_execute(
            self, ctx, *, call, tool_def,
            args, handler):
        print('tool', call.tool_name)
        return await handler(args)

Order: wrap_* enters → before_* in list order → the operation → after_* in reverse → wraps exit.

Pydantic AI Field Guide · Capabilities · docs/hooks.md, docs/capabilities/custom.md

Hooks cover the run, each graph node, model requests (before, prepare, after, wrap, error), tool argument validation and execution, output validation and processing, prepare_tools, deferred tool calls and events. Register them with @hooks.on.name or constructor keyword arguments; tool hooks can be filtered with tools=[...] and bounded with timeout=. Error hooks re-raise to propagate or return a value to recover, which is how you turn exceptions into ModelRetry or ToolFailed. ModelRetry raised from a model-request hook uses the output retry budget. Changing request_context.messages affects only that request; ctx.messages is the persistent history. For anything reusable, subclass AbstractCapability: implement for_run to return a fresh instance so state doesn’t leak between runs, and combine configuration methods (get_toolset, get_instructions, get_model_settings, get_wrapper_model) with hooks. SkipModelRequest and SkipToolExecution short-circuit an operation. Use ctx.enqueue to steer the model. Implement from_spec and pass custom_capability_types= to use it in YAML agent specs. Ideas: PII redaction, timing middleware, audit logs, cost tracking, guardrails.
