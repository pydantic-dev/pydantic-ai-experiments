Pydantic AI Field Guide · Roadmap

The deck follows the order you would learn the library in. Sections 1 and 2 are the foundation: almost everything else is built on the Agent, its run loop and the RunContext. Section 3 covers how agents act on the world, through tools and through capabilities, which are version 2’s main extension unit. Section 4 is about which model runs the agent and how users reach it. Sections 5 and 6 cover scaling up to several agents and measuring quality. Section 7 is the separate pydantic-ai-harness package. Section 8 turns all of it into a hands-on learning plan.
