Pydantic AI Field Guide · Migration · docs/migration.md, docs/changelog.md

Most blog posts and many answers online were written for version 1, and a lot of them no longer run. This table collects the renames the research found most often. The pattern behind most of them: agent keyword arguments that configured behaviour became capabilities in a list, so they compose and can be declared in YAML agent specs. Other changes worth knowing: Dataset(name=...) is now required in Pydantic Evals; FunctionToolset.tool requires a RunContext first parameter; the ACI integration was removed (wrap the SDK with Tool.from_schema); deps_type defaults to object instead of None; retry budgets can be split with retries={'tools': N, 'output': M}. docs/migration.md lists every change. A coding-agent tip: uvx library-skills --all --claude installs Pydantic AI skills into Claude Code so it writes v2-style code.
