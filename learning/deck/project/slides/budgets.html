02 · Core agent

Every failure mode has its own budget

agent = Agent('anthropic:claude-sonnet-5-5', tool_timeout=30, retries={'tools': 3, 'output': 2},
    capabilities=[RetryOnModelErrors(max_attempts=4), ModelFallback('openai:gpt-6.1-sol'), Caching()])

limits = UsageLimits(request_limit=25, cost_limit=Decimal('0.50'))  # USD, via genai-prices
result = await agent.run(prompt, usage_limits=limits, timeout=120)  # RunTimedOut after 2 min

UsageLimits

Spend

Requests (default 50), tool calls, tokens, cost. Raises UsageLimitExceeded.

retries=

Retries

Separate tool and output budgets. Nine layers exist and they multiply: pick one owner.

timeout

Time

Per attempt, per request, per tool, per run. ctx.remaining_time() inside tools.

capture_run_messages

Recovery

Failed runs keep history; resume with no new prompt and finished tools don’t re-run.

This is close to the production recipe from docs/production.md. UsageLimits caps a single run: request_limit defaults to 50, plus tool_calls_limit, token limits and cost_limit in US dollars, estimated with genai-prices. Token and cost limits are checked after billing, and limits reset per run unless you pass conversation=. Retries: ModelRetry from a tool or validator asks the model to fix things and consumes budget; ToolFailed reports a definitive failure without consuming budget; RetryOnModelErrors retries 429s and 5xx; ModelFallback switches models. The docs list nine retry layers (transport, SDK, durable engine, RetryOnModelErrors, fallback, RetryModelRequest, tool, output, hooks) and warn that they multiply, so choose one layer to own retries and set the SDK’s max_retries to 0 when you use fallback. Timeouts: model_settings timeout is one attempt, request_timeout is one clock across attempts, first_event_timeout lets a fallback take over a stalled stream, tool_timeout bounds tools, and run(timeout=) raises RunTimedOut with resumable messages. capture_run_messages() keeps the history of a run that raised, so you can resume it.
