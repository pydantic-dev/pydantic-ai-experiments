Realtime voice is the same agent, live

agent = Agent(instructions='You take reservations.')

@agent.tool_plain
async def consult(question: str) -> str:
    """Ask a text agent hard questions."""
    return (await supervisor.run(question)).output

async def main():
    rt = agent.realtime('openai:gpt-realtime-2.1')
    async with rt.session() as session:
        await session.send('Greet the caller.')
        async for ev in session:
            if isinstance(ev, RealtimeTurnCompleteEvent):
                break
        history = session.all_messages()  # → text agent

  • Audio: 16-bit mono PCM; server VAD or push-to-talk.
  • Providers: OpenAI, Azure, Gemini Live, xAI, ElevenLabs.
  • Deploy: browser WebRTC + sideband, or a WebSocket relay.
  • No output_type: hand the call’s history to a text agent for structured results.
  • No test model: voice needs a real key.

Pydantic AI Field Guide · Realtime · docs/realtime/*.md, examples/realtime_*

agent.realtime(model, ...) takes the same arguments as run (deps, instructions, toolsets, capabilities, usage limits, message_history or conversation) and returns an AgentRealtime; .session() opens a persistent RealtimeSession. Audio is raw signed 16-bit little-endian mono PCM: capture at session.audio_input_sample_rate and play at audio_output_sample_rate, in chunks of about 100 ms. Server voice-activity detection is the default; for push-to-talk set turn_detection=False and call send_audio, commit_audio, create_response. RealtimeTurnCompleteEvent is the only reliable end-of-turn signal. Tools run on your backend with the same validation, retries and hooks as text runs, but approval-gated tools need a HandleDeferredToolCalls capability because a call can’t pause. Realtime runs have no output_type, so the realtime_handoff example passes session.all_messages() to a text agent with output_type=SupportTicket. Deployment: with OpenAI and Azure, media can go browser-to-provider over WebRTC while your server attaches a sideband session that runs tools; note that close() on a sideband only detaches, and the call stays billed until hang_up(). Examples to try in order: realtime_text_to_audio, realtime_handoff, realtime_voice, realtime_webrtc, realtime_camera.
