Pydantic AI Field Guide · Experiments · cloned at /home/ubuntu/pydantic-dev/pydantic-ai-experiments

These ten are ordered by difficulty and drawn from the experiment lists in all six research notes. 1 to 3 need no API key at all: use 'test', TestModel and FunctionModel. For 2, script a FunctionModel response that contains text plus a tool call to see run_stream end before the tool runs. For 3, raise ModelRetry twice and ToolFailed once and inspect ToolReturnPart.outcome. For 4, end the run with DeferredToolRequests, dump result.conversation with ConversationTypeAdapter, and resume in a fresh process with deferred_tool_results; then try HandleDeferredToolCalls instead. For 5, use InMemoryConversationStore first. For 6, compare tool_error_behavior='retry' and 'failed'. For 7, stack your capability with Hooks() and print the order hooks fire in. For 8, store cases with dataset.to_file to get schema autocomplete, and compare runs with report.print(baseline=old). For 9, carry (index, item) and use reduce_dict_update to restore input order. For 10, seed a repo with a failing test and compare against plain Coder() in Logfire. Stretch goals from the research: DBOS on SQLite with a mid-run kill, a local decision model with system-one: on Ollama, and a realtime text-to-audio session.
