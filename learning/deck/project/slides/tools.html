03 · Tools & capabilities

A tool is a typed function the model may call

agent = Agent('test', deps_type=str)

@agent.tool  # takes RunContext first
def player(ctx: RunContext[str]) -> str:
    """Get the player's name."""
    return ctx.deps

@agent.tool_plain(require_parameter_descriptions=True)
def convert(amount: float, to: str) -> str:
    """Convert USD to another currency.
    Args:
        amount: Amount in USD.
        to: ISO 4217 currency code.
    """
    return rates.convert(amount, to)

  • Signature → JSON schema; args are validated by Pydantic before your code runs.
  • Docstring → descriptions (Google, NumPy, Sphinx styles via Griffe).
  • Prefer async def: sync tools run in a thread pool.
  • Return text, models, images or ToolReturn (value + extra content + app-only metadata).
  • Calls in one response run in parallel; sequential=True makes a barrier.

@agent.tool functions take RunContext as their first parameter, giving access to deps, ctx.retry, ctx.tool_call_id and ctx.enqueue. @agent.tool_plain functions take no context. You can also pass functions or Tool objects in Agent(tools=[...]). Every parameter except RunContext goes into the schema, and Griffe parses the docstring into the tool description and per-parameter descriptions; only the description, Args, the first Returns entry and Note or Warning sections are sent. Tool(fn, ...) makes a reusable definition with options such as prepare, strict, requires_approval and defer_loading, and Tool.from_schema wraps functions that have no usable signature (it does not validate arguments). A per-tool prepare(ctx, tool_def) can hide or rewrite the tool on each step, for example to show admin tools only to admins; use dataclasses.replace rather than building a fresh ToolDefinition. ToolReturn splits the result into return_value for the model, content as a separate user message (screenshots), and metadata the model never sees. Tool search: defer_loading=True plus the ToolSearch capability hides large tool catalogs until the model searches for them.
