04 · Models & interfaces

Settings stack up; fallbacks and local models plug in

model = GoogleModel('gemini-3.8-flash',
    settings=ModelSettings(temperature=0.8, max_tokens=500))
agent = Agent(model, model_settings={'temperature': 0.5},
    capabilities=[ModelFallback('anthropic:claude-sonnet-5-5')])
agent.run_sync('Hi', model_settings={'temperature': 0.0})
# effective: temperature 0.0, max_tokens 500

# local and OpenAI-compatible servers
local = OllamaModel('qwen3', provider=OllamaProvider(
    base_url='http://localhost:11434/v1'))
custom = OpenAIChatModel('my-model',
    provider=OpenAICompatibleProvider('my-svc',
        base_url='http://localhost:8000/v1', api_key='x'))

  • Precedence: model < agent < capability < run.
  • thinking: one portable reasoning knob.
  • ModelFallback also catches content filters and truncation.
  • Profiles describe a model; capabilities change the agent.
  • Unsupported knobs are ignored silently.

ModelSettings is a TypedDict: max_tokens, temperature, top_p, top_k, timeout, request_timeout, first_event_timeout, max_retries, parallel_tool_calls, tool_choice, seed, penalties, stop_sequences, extra_headers, thinking, citations, cache, service_tier and extra_body. Settings merge from the model, then the agent, then capabilities such as Thinking(), then the run; setting a key to None clears an inherited value, and agent- or run-level settings can be a lambda of ctx evaluated before each request. Provider-specific classes (AnthropicModelSettings, OpenAIModelSettings, GoogleModelSettings) add fields that override the portable ones. Fallback: ModelFallback is the in-agent way; it falls back on ModelAPIError plus ContentFilterError and OutputTokenLimitExceeded by default, and you can pass exception or response handlers via fallback_on. Set the SDK’s max_retries to 0 so failover is fast. Local models: Ollama’s base URL includes /v1; self-hosted Ollama enforces NativeOutput schemas but Ollama Cloud does not. vLLM needs --enable-auto-tool-choice for tools. OpenAICompatibleProvider works with any OpenAI-shaped server; fix quirks with OpenAIModelProfile flags.
