01 · First agent

Your first agent runs with no API key

from pydantic_ai import Agent, RunContext

roulette = Agent(
    'test', deps_type=int, output_type=bool,
    instructions='Use roulette_wheel.',
)

@roulette.tool
async def roulette_wheel(
    ctx: RunContext[int], square: int
) -> str:
    """check if the square is a winner"""
    return 'win' if square == ctx.deps else 'lose'

r = roulette.run_sync('Bet on 18', deps=18)
print(r.output, r.usage)

  • 'test' is TestModel: it calls every tool with schema-valid args, then returns valid output.
  • The docstring becomes the tool description; the signature becomes its JSON schema.
  • deps are injected per run and read via ctx.deps.
  • Swap 'test' for 'anthropic:claude-sonnet-5-5' when you’re ready.

Pydantic AI Field Guide · First agent · docs/agent.md, docs/install.md

This is the roulette example from the docs, pointed at TestModel. TestModel is the fastest way to learn: it inspects your tools, calls each one with arguments that satisfy the schema, then generates output that satisfies output_type. Nothing leaves your machine. Things to notice: output_type=bool means result.output is a real Python bool; deps_type=int is only for type checking, and the actual value comes from deps=18 on the run; result.usage tells you requests and tokens. Install: Python 3.11 or newer. pydantic-ai is the full install, and pydantic-ai-slim with extras such as [openai,anthropic] keeps production installs small. To try a real model, set ANTHROPIC_API_KEY or OPENAI_API_KEY and change the model string.
