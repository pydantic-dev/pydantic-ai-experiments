The output type is the contract

class Box(BaseModel):
    width: int
    height: int
    units: str

extractor = Agent(
    'openai:gpt-6-luna',
    output_type=[Box, str],  # data, or ask back
    instructions='Extract box dims or ask.')
extractor.run_sync('The box is 10x20 cm').output
# Box(width=10, height=20, units='cm')

triage = Agent('openai:gpt-6.1-sol',
    output_type=Choices({'refund': 'Wants money back.',
        'replace': 'Wants a new unit.'}))

Output modes

  • ToolOutput (default): an output tool the model calls.
  • NativeOutput: the provider’s JSON-schema mode.
  • PromptedOutput: schema in the prompt; good for weak or local models.
  • TextOutput(fn): plain text passed through your function.

Also: unions, lists, TypedDicts, dataclasses, scalars, BinaryImage, and output functions that end the run.

Pydantic AI Field Guide · Core agent · docs/output.md

output_type decides what ends a run and what result.output is. Each member of a union or list becomes its own output tool, so [Box, str] lets the model either return data or ask a clarifying question. Choices, new in version 2, is for options known only at run time, and Choice(desc, value=...) maps a key to an object or a callable action. StructuredDict(schema) takes a raw JSON schema but is not validated. An output function, passed as output_type, must be called by the model; its return value becomes the output, it can take ctx and raise ModelRetry. That is also how a router agent hands off to sub-agents. Modes: ToolOutput is the default and takes name, description, max_retries and strict; NativeOutput uses the provider’s structured-output mode; PromptedOutput puts the schema in the instructions. Gotchas: text cut off by the token limit is still returned, so check result.response.finish_reason == 'length'; structured output cut off raises OutputTokenLimitExceeded. Use case ideas: invoice-to-JSON, contact extraction, ticket classification.
