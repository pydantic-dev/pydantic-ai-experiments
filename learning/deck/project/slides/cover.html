from pydantic import BaseModel
from pydantic_ai import Agent

class City(BaseModel):
    name: str
    country: str

agent = Agent('test', output_type=City)
r = agent.run_sync('The windy city')
print(r.output)
# City(name='a', country='a')
# 'test' = TestModel: no API key

Welcome. This deck was built from Pydantic AI’s own docs and example projects at version 2.71 (the main branch, cloned into the pydantic-dev org as pydantic-ai-experiments). Six research passes covered the core agent, tools and capabilities, models and interfaces, multi-agent and evals, the Harness capability library, and the examples. Every code sample uses real API names checked against the source. Where possible the samples use the model string 'test', which is the offline TestModel, so you can run them with no API key. The speaker notes on each slide carry extra detail and gotchas.
