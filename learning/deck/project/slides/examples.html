Pydantic AI Field Guide · Examples · examples/pydantic_ai_examples, docs/examples/*.md

Setup from the cloned repo: uv sync --extra examples, export OPENAI_API_KEY (most examples) or GEMINI_API_KEY, then uv run -m pydantic_ai_examples.module_name. --copy-to examples/ copies the top-level files for editing, but skips the sub-packages (ag_ui, evals, realtime_camera, realtime_webrtc, slack_lead_qualifier). No key at all: wrap any example in agent.override(model=TestModel()) to check its wiring, or run the FunctionModel snippet from docs/examples/cancellation.md. Free tiers: Gemini covers sql_gen (with a local Postgres in Docker), stream_markdown and realtime_camera; Groq covers roulette_wheel and stream_markdown. Not covered by any example, so use the feature docs: pydantic_graph, durable execution, MCP, FallbackModel and agent.iter, and Pydantic AI embeddings. Quirks found: weather-agent.md asks for API keys the code no longer uses, bank_support.py uses a module-global cursor (fix before reuse), and evals script 01 overwrites the committed dataset, so run it last. Gap-filling ideas: rebuild flight_booking as a graph, add ModelFallback to chat_app, expose bank_support tools over MCP.
