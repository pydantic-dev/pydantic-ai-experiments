02 · Core agent

Stream text, or structured data as it validates

class Profile(TypedDict):
    name: str
    bio: NotRequired[str]  # lets partials validate

agent = Agent('openai:gpt-6.1-sol', output_type=Profile)

async def main():
    async with agent.run_stream('Ben, likes dogs') as r:
        async for p in r.stream_output(debounce_by=None):
            print(p)  # growing snapshot

# a stop button: one token per run
token = CancellationToken()
task = asyncio.create_task(
    agent.run(q, cancellation_token=token))
token.cancel()  # raises RunCancelled, history kept

  • stream_text() for chat; delta=True gives tokens instead of snapshots.
  • stream_output() yields partially validated objects: progressive forms and tables.
  • RunCancelled.all_messages() lets the next run resume from where you stopped.

Examples to run

stream_markdown (live Markdown), stream_whales (live table), cancel_and_resume (Esc to stop).

StreamedRunResult gives you stream_text (with delta and debounce_by options), stream_output for structured snapshots, stream_response, get_output, cancel, and .result for the settled AgentRunResult. The trick for structured streaming: fields must be optional (NotRequired in a TypedDict) so that an incomplete object still validates. That is exactly what stream_whales does to redraw a table as whale records arrive. Structured streaming also needs a provider that streams tool arguments. Note that stream_text(delta=True) does not add the final message to history. Cancellation: create a CancellationToken per run, pass it as cancellation_token, and call token.cancel() from anywhere, even another thread, which is the only way to stop a blocked run_sync. The run raises RunCancelled, whose all_messages() can be passed back as message_history; dangling tool calls are repaired automatically. Cancellation is cooperative: a sync def tool keeps running. Run-level timeout=seconds raises RunTimedOut, which is both a RunCancelled and a TimeoutError.
